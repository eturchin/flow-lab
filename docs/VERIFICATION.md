## Что проверено сквозными тестами

Создание и изменение сценариев, неизменность исторического снимка, одинаковые результаты повторного запуска, сравнение, постраничный журнал ошибок, корректные HTTP-статусы, каскадное удаление. Проверены SignalR, отмена активного запуска и блокировка удаления активного сценария.

Проверка ёмкости: одиннадцать одновременных запросов на запуск дают десять принятых задач и один HTTP 429. В одном снимке истории выполняется не более двух задач, остальные ожидают. После отмены все задачи приходят в терминальное состояние.

Браузерный сценарий: создание → настройка → первый запуск → изменение нагрузки → второй запуск → сравнение → журнал ошибок → переключение графиков → mobile viewport 390px → удаление. Ошибок JavaScript не обнаружено; горизонтального переполнения страницы нет. Desktop/mobile скриншоты осмотрены.

## Аварийное завершение

В отдельной ручной проверке создан временный сценарий и десять длительных запусков. Перед принудительной остановкой процесса: **2 Running + 8 Queued**. После повторного старта: **10 Failed**, сообщение «Приложение остановлено до завершения запуска», ни одного зависшего Queued/Running. Временный сценарий после проверки удалён.
